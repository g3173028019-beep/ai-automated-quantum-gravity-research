# 46 — When Two Scalar Modes Share the Einstein Light Cone

For positive strongly hyperbolic scalar modes with independent gradients on an open attained family, equality of the scalar and Einstein characteristic sets forces a positive nonlinear sigma model with a potential. Two exact constrained data families distinguish this property from hyperbolicity alone.

**Scope.** Classical minimally coupled first-derivative two-real-scalar actions in four dimensions, with the Einstein metric as the reference cone and attained rank-two jets. Local smooth result; analyticity continues Hessian vanishing, not positivity.
