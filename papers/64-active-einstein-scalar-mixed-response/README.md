# Paper 64. A sourced mixed Einstein–scalar response on a compact Cauchy slab

A finite retarded graviton–scalar response is nonzero on a genuinely coupled four-dimensional background. The Hessians of the actual marked sources cancel the two collapsed-leg Ward terms.

**Scope.** One normalized tree coefficient on a marked compact CMC slab; active Einstein–massless-scalar backgrounds on the constructed branch.
