# 27B · Parity-odd Weyl-cubic gravity with fixed physical multipliers

**[PDF](manuscript.pdf) · [LaTeX source](main.tex)**

Reorganizes the fixed-multiplier canonical reduction and proves a nonzero finite-collar invariant for Schwarzschild polar-to-axial mixing, together with a separate nonzero compact physical bracket.

This is a first-order classical result on the Einstein branch. It does not assert finite-coupling hyperbolicity or quantum constraint anomaly freedom.
