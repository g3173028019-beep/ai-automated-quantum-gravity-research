# Paper 73. Crossed dispersion from real-transfer graviton data in five dimensions

Reconstructs a smeared crossing-symmetric all-polarization sum rule from real-transfer data and supplies a signed Gauss–Bonnet test.

**Scope.** Weak/tree order under the stated ordinary low-energy contour, Ward locality and positive partial-wave inputs.
