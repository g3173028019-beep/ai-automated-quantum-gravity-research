# Paper 30: verification and build

Check the covering/seed from Galloway–Ling, the normal-connection identity and Killing-field integral, the equal pole-period obstruction, and Lafuente López’s global identification. Cross-checked analytically; no numerical dependency.

This is universal-cover metric rigidity, not a classification of deck groups or of arbitrary double-null spacetimes. The proof takes Galloway–Ling’s null foliations as input and supplies the zero-twist, compact-warp and global-continuation steps.

Build from this directory with two passes of `pdflatex -halt-on-error main.tex`; only ordinary LaTeX mathematics, geometry and hyperlink packages are required. The generated `main.pdf` is distributed as `manuscript.pdf`.
