# 33B — Determining an Evolving Lorentzian Geometry with Uniform Mass Control

Exact calibrated retarded aperture responses and synchronized spatially uniform mass variations recover an evolving Lorentzian geometry in the stated setting; the twisted-cap extension uses an independent calibration.

Companion to Paper 33. Includes an unconditional orthogonally static compact-cap calibration under its data assumptions, a conditional twisted-cap extension and exact ambiguities for missing control times or uncontrolled spatial profiles.
