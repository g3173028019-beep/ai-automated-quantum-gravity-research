# 43 — Gravitational readouts of a localized non-Abelian null-beam collision

For smooth characteristic Einstein–Yang–Mills data in the stated localized collision, a normal Ricci term detects the commutator norm, while an independent signed shape term changes the optical readout.

Uses local characteristic existence for the classical coupled equations. The proof identifies invariant mixed electric and magnetic terms, derives a local optical measurement, and compares it with finite Wilson loops. No quantization is assumed.
