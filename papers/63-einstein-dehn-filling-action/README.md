# Paper 63. Action asymptotics for Einstein–Dehn fillings at a compact hyperbolic mirror

The reflected half-fill action has an explicit leading coefficient and a uniform sixth-order inverse-length remainder; an arithmetic sequence gives distinct Einstein halves.

**Scope.** Orientable hyperbolic four-manifold with toral cusps and compact connected geodesic boundary; long primitive fillings and converging induced boundary metrics.
