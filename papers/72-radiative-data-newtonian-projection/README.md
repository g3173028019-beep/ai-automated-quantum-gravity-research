# Paper 72. Radiative data lost by the Newtonian projection

On attainable Einstein–Euler initial data the fast outgoing graviton pairs are absent in the Newtonian projection. The positive finite-radius escape coefficient equals the normalized mixed ADM mass Hessian.

**Scope.** Fixed-radius coefficient extraction on the specified initial family; the radiation limit is taken afterward.
