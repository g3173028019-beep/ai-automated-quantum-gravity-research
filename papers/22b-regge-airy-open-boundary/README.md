# Paper 22B. An open-boundary Lorentzian Regge saddle crossing with a curvature insertion

An open set with all 14 independent marked boundary controls has a real Lorentzian saddle crossing. A marked curvature insertion gives an explicit nonzero Airy-derivative coefficient.

**Scope.** Local real contour near the stated Lorentzian crossing with fixed causal marking; a companion to Paper 22.
