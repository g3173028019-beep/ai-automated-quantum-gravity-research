# Paper 71. Positive Hadamard states for linearized Einstein wave maps

Positive physical Hadamard covariances with exact Green CCR for curved targets; a separate massive asymptotically flat construction realizes them on a fixed weighted base.

**Scope.** Closed Cauchy surfaces and, separately, the controlled one-ended massive branch with scalar decay p>3.
