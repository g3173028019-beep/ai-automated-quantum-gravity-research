# 44 — Gravitational Region Sewing: Minimal Corner Registers and Continuous Radiative Loads

The minimum independent register for a bracket-preserving linear dressing is the cross-pairing rank. Linked linear graviton charges require ten pairs per independent link for a single electric–magnetic pairing. A propagating polarization instead has continuous spectral load, yielding quantitative finite-reservoir obstructions on planar and Schwarzschild cuts.

**Scope.** Finite independent linear dressings of marked charge families, and positive closed linear reservoirs at fixed momentum or in one canonical Schwarzschild parity channel. No unrestricted nonlinear reservoir or nonlinear quantum gluing claim.
