# Paper 69. Controlled noncompact sewing and fixed-colour rank in Lorentzian EPRL

A joint Galerkin, radial, and quadrature limit controls fixed-colour finite foams. The same external sector has ranks 16 versus at most 2 and 81 versus at most 3 across the specified move.

**Scope.** Lorentzian principal-series fixed-colour foams; the rank comparison is for the designated resolved sector.
